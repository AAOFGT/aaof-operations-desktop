# AAOF Operations Desktop Releases

This repository is the public, release-only distribution endpoint for AAOF Operations Desktop.

Only artifacts produced by the protected cross-platform signing workflow and approved through the acceptance-gated promotion workflow may be published here. Source code, credentials, operational data, and unsigned builds do not belong in this repository.

Staff should obtain installers through the authenticated AAOF Operations portal, which validates release metadata and checksums before presenting download links.
